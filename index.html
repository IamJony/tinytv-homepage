    Instalación en FLinux / Tiny Core

    1. Clonar el repositorio: 
    git clone https://github.com/IamJony/tinytv.git
cd tinytv
    2. Instalar el paquete .tcz precompilado (32 bits): 
    # Mueve el paquete al directorio de extensiones de Tiny Core
sudo cp tinytv.tcz /etc/sysconfig/tcedir/optional/
echo "tinytv.tcz" | sudo tee -a /etc/sysconfig/tcedir/onboot.lst
sudo tce-load -i tinytv.tcz
